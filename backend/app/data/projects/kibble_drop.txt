**Category:** Full-stack SaaS / E-commerce

**Description:**
A modern platform for managing pet food subscriptions.

**Technologies:**
- Next.js
- Prisma
- PostgreSQL
- Stripe
- Tailwind CSS
- shadcn/ui

**Features:**
- Authentication
- Subscription management
- Payment integration
- Modern responsive interface
- Database-driven application architecture
